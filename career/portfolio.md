# Portfolio and interviews

For each project publish a short README, architecture diagram, threat model,
commands or code that is safe to reproduce, test results, and remediation.
Remove secrets, personal data, target identifiers, and exploit payloads.

Interview practice: explain one incident timeline, prioritize three risks with
assumptions, review a small code change, and write a concise incident update.
Ask employers about on-call, training, authorization, data access, and how
success is measured.
