# Career development

Choose roles by work, not title: SOC/detection, vulnerability management,
security engineering, AppSec, cloud, DFIR, testing, GRC, or security
architecture. Read job postings, map requirements to evidence, and revisit
every quarter.

## Evidence employers can assess

- Two or three concise reports with sanitized artifacts and remediation.
- A public lab repository with reproducible setup and safe scope.
- Clear writing: one executive summary and one technical appendix.
- Collaboration: issue, review, test, and change history.

Practice explaining a risk to a non-specialist, triaging ambiguous alerts,
and describing what you would do when you do not know. See
[certifications](certifications.md) and [portfolio guidance](portfolio.md).
