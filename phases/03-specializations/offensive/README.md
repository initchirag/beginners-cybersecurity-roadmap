# Offensive security — authorized assessment

See the expanded [Offensive Security domain guide](../../../domains/offensive/README.md)
for the full concepts, tools, IOC/TTP, and framework checklist.

Study scoping, rules of engagement, reconnaissance from permitted data,
configuration review, web testing, privilege boundaries, evidence handling,
risk ratings, and clear remediation. Use only intentionally vulnerable labs;
do not scan public systems.

**Portfolio:** a sanitized assessment report for Juice Shop or WebGoat that
includes authorization assumptions, reproduction at a safe level, impact,
fix, and retest. References:
[OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/),
[PTES](http://www.pentest-standard.org/).
