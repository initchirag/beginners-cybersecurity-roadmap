# DFIR — digital forensics and incident response

See the expanded [DFIR domain guide](../../../domains/dfir/README.md) and
[Incident Response guide](../../../domains/incident-response/README.md).

Learn incident lifecycle, evidence preservation, time normalization, disk and
memory concepts, timeline analysis, containment decisions, eradication,
recovery, and communications. Keep originals read-only, hash collected files,
and record chain of custody.

**Portfolio:** a synthetic incident timeline and executive/technical report.
References: [NIST SP 800-61](https://csrc.nist.gov/pubs/sp/800/61/r2/final),
[CISA incident response](https://www.cisa.gov/topics/cyber-threats-and-advisories/incident-response).
