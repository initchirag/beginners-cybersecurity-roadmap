# Cloud security

See the expanded [Cloud domain guide](../../../domains/cloud/README.md).

Learn shared responsibility, identity and access management, network
segmentation, logging, key management, storage exposure, infrastructure as
code, containers, incident response, and cost-aware guardrails. Use a free
tier or local emulator and set budgets and automatic cleanup.

**Portfolio:** a least-privilege architecture diagram plus policy-as-code
checks and a recovery exercise. References:
[AWS Security](https://aws.amazon.com/security/), [Azure security](https://learn.microsoft.com/azure/security/),
[Google Cloud security](https://cloud.google.com/security).
