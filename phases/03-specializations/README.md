# Phase 3 — Specializations

Choose one primary path for 8–16 weeks and maintain broad literacy. Every path
produces a report, evidence, remediation, and a lessons-learned section.

The full [domain index](../../domains/README.md) includes additional cloud,
mobile, wireless, AI, architecture, and assurance guides.

| Path | Core outcome | Guide |
| --- | --- | --- |
| Blue team | Detect, contain and improve resilience | [blue-team](blue-team/README.md) |
| Offensive security | Validate controls with authorization | [offensive](offensive/README.md) |
| DFIR | Preserve evidence and explain incidents | [dfir](dfir/README.md) |
| Application security | Make secure delivery repeatable | [appsec](appsec/README.md) |
| Cloud security | Govern identity and workloads | [cloud](cloud/README.md) |

Use the [MITRE ATT&CK](https://attack.mitre.org/) knowledge base to describe
behaviors and pair each technique with preventive and detective controls.
