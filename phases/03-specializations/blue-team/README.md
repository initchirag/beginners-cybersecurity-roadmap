# Blue team — detection and response

See the expanded [Defensive SOC domain guide](../../../domains/defensive-soc/README.md)
for the full concepts, tools, IOC/TTP, and framework checklist.

Learn asset inventory, secure configuration, centralized logs, detection
engineering, alert triage, threat hunting, vulnerability management, backup
testing, and incident coordination. Build a small lab with Sysmon or native
audit logs, an open-source SIEM, and a documented escalation matrix.

**Portfolio:** a detection rule with test data, triage decision tree, and
post-incident improvements. References:
[CIS Controls](https://www.cisecurity.org/controls),
[NIST CSF 2.0](https://www.nist.gov/cyberframework),
[Sigma](https://sigmahq.io/).
