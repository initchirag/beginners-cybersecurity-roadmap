# Application security — secure delivery

See the expanded [Web/API guide](../../../domains/web-api/README.md) and
[DevSecOps guide](../../../domains/devsecops/README.md).

Learn threat modeling, secure design, code review, dependency and secrets
management, SAST/DAST trade-offs, API authorization, security tests, release
gates, and vulnerability disclosure. Integrate checks into a toy CI pipeline
without blocking developers on unreviewed noise.

**Portfolio:** a threat model, security test suite, dependency policy, and
measured remediation. References:
[OWASP SAMM](https://owaspsamm.org/), [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/),
[OpenSSF](https://openssf.org/).
