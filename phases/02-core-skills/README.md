# Phase 2 — Core security skills

**Suggested pace:** 10–14 weeks. Apply every concept to prevention, detection,
and recovery—not only to finding a weakness.

## Study areas

Detailed companion guides: [programming and cryptography](../../domains/programming-crypto/README.md)
and [web/API security](../../domains/web-api/README.md).

- **Identity and Windows:** Active Directory concepts, Kerberos at a high
  level, Group Policy, secure administration, PowerShell, and event IDs.
- **Programming:** Python, Bash and PowerShell; parsing structured data,
  APIs, tests, error handling, secrets management, and secure defaults.
- **Web and API security:** HTTP, sessions, access control, input handling,
  SSRF, injection, XSS, dependency risk, logging, and OWASP ASVS.
- **Cryptography:** threat models, hashes vs encryption, AEAD, key lifecycle,
  certificates, TLS, password hashing, signatures, and common failure modes.
- **Security operations:** asset inventory, vulnerability management, alert
  triage, risk statements, backups, and incident documentation.

## Projects

1. Parse web and authentication logs into a small timeline.
2. Threat-model a toy API and implement authorization tests.
3. Create a baseline-hardening checklist and verify it after a snapshot.
4. Build a local alert rule with a false-positive note and response steps.

Use [OWASP Top 10](https://owasp.org/www-project-top-ten/) and
[NIST SP 800-61](https://csrc.nist.gov/pubs/sp/800/61/r2/final) as references.
Continue with [specializations](../03-specializations/README.md).
