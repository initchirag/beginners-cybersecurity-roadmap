# Security Policy

This repository is educational documentation rather than a production software service.

## Reporting a security issue

If you discover a vulnerability in code shipped by this repository, please avoid publishing sensitive exploit details in a public issue. Contact the maintainers privately through the repository's configured security contact.

## Educational safety

All practical security testing referenced here must be performed against:
- systems you own
- isolated local labs
- intentionally vulnerable training environments
- CTF infrastructure
- systems for which you have explicit authorization

Never use this roadmap as permission to test a third-party system.

## Secrets

Never commit passwords, API keys, tokens, private keys, personal data, or real incident evidence.

## Content concerns

For unsafe or misleading security instructions, open a documentation issue or contact maintainers so the material can be reviewed.
