# Curated resources

Prefer primary, maintained sources and verify dates before relying on guidance.

- **Frameworks:** [NIST CSF](https://www.nist.gov/cyberframework),
  [CIS Benchmarks](https://www.cisecurity.org/cis-benchmarks),
  [ISO/IEC 27001 overview](https://www.iso.org/isoiec-27001-information-security.html).
- **Web/AppSec:** [OWASP](https://owasp.org/), [PortSwigger Academy](https://portswigger.net/web-security).
- **Practice:** [OverTheWire](https://overthewire.org/wargames/),
  [TryHackMe](https://tryhackme.com/), [Hack The Box Academy](https://academy.hackthebox.com/).
- **Threats:** [MITRE ATT&CK](https://attack.mitre.org/),
  [CISA alerts](https://www.cisa.gov/news-events/cybersecurity-advisories).
- **Standards/news:** [NIST CSRC](https://csrc.nist.gov/), [SANS ISC](https://isc.sans.edu/).

Labs are not permission to test public infrastructure; read each platform's rules.
