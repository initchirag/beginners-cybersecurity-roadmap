# Projects and home lab

Build a small, disposable lab: host-only networking, snapshots, synthetic
data, no shared passwords, and outbound access disabled unless required.

## Project ladder

1. **Beginner:** packet annotation, Linux/Windows hardening, and a log parser.
2. **Intermediate:** vulnerable web-app assessment with a remediation retest;
   a basic SIEM dashboard; or a backup/restore drill.
3. **Advanced:** detection-as-code, cloud guardrails, secure CI, or a
   cross-source incident timeline.

Each README/report should state scope, assumptions, data handling, evidence,
risk, fix, verification, and limitations. Use purpose-built targets:
[Juice Shop](https://owasp.org/www-project-juice-shop/),
[WebGoat](https://owasp.org/www-project-webgoat/), and
[picoCTF](https://picoctf.org/).
